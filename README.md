# Secure Vault

Secure Vault is a MERN stack application focused on secure note management with JWT authentication and encrypted user data handling.

## Features

- User registration and login
- JWT authentication
- Protected routes
- Create, edit and delete secure notes
- MongoDB integration
- Responsive cyberpunk-inspired UI

## Tech Stack

### Frontend
- React
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
